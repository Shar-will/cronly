# Gradient Grid Shader

Free composition of the shaders.com Gradient Grid look, using the public `shaders` npm package (no Pro preset). DialKit is on the right for live tweaks.

Stack:

- `MeshGradient` — drifting color field
- `Grid` — line overlay
- `FlowField` — shared distortion
- `FilmGrain` — analog grain

```bash
npm install
npm run dev
```
